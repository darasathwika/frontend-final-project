2. Challenges Problem Statement

The Core Problem

Limitations of conventional and legacy feedback collection methods

Scattered & Unorganized Data

Organizations often receive reviews through informal emails, random social channels, or disconnected text forms with no unified central database.

Lack of Real-Time Analytics

Standard survey tools dump data into massive raw tables. Decision-makers lack dynamic monthly trends, star breakdowns, and category-level KPIs.

High Submission Friction

Overly long forms with poor UI/UX discourage users from completing submissions. Absence of interactive star ratings leads to abandonment.

Zero Administrative Governance

Inability to search keywords, filter by ratings, edit entries, delete outdated logs, or export reports to CSV for audit reviews.

3. Goals Project Objectives & Scope

Objectives & Scope

Core targets defined for the development of FeedPulse

1. Seamless User Interaction

Build an intuitive submission form with interactive 1-to-5 star rating selector, 8 dedicated categories, and dynamic validation.

2. Real-Time Dynamic Dashboard

Compute positive, negative, and average star ratings automatically, with 4 Chart.js visualizations that update without page reloads.

3. End-to-End Feedback Management

Deliver full CRUD (Create, Read, Update, Delete) with live search, multi-level category/rating filtering, and CSV export.

4. Role-Based Auth & Persistence

Secure login/signup workflows with password visibility toggles, session persistence, and zero-loss local database storage.

4. Architecture System Design & Data Flow

3-Tier Client Architecture

Modular Single Page Application (SPA) architecture

Presentation Layer

HTML5 • CSS3 Modern Grid/Flex • FontAwesome • Confetti

Application Logic

Hash Router • Form Validator • Chart.js Engine • CRUD State

Persistence Layer

HTML5 Web LocalStorage • Pre-seeded JSON • CSV Exporter

Data Flow Highlights:
  • User actions trigger modular events in script.js without triggering full browser reloads.
  • Client state computes average ratings and sentiment split instantly in memory and syncs with localStorage.
  • Chart.js canvases automatically re-render when feedbacks are added, edited, or deleted.

10. Quality & Security Validation & Error Handling

Validation & Error Handling

Strict client-side safeguards ensuring high data integrity

Email & Phone

Regex-based email format validation and strict 7-to-15 digit phone validation preventing invalid records.

Password Match

Real-time visual comparison verifying that Password and Confirm Password match before form submission is allowed.

XSS Prevention

Custom escapeHTML() utility sanitizes all user input strings before rendering into the DOM, preventing script injections.
